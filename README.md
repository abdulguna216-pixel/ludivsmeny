# Люди в смену

Сайт: https://lyudivsmenu.ru/

## Автоматическое обновление

Публикуются `index.html`, `styles.css`, `fonts.css`, `script.js` и файлы из `assets/` в ветке `main`. Отправьте commit в `main` или влейте pull request — обновление обычно появится на сайте через 1–2 минуты.

Новые изображения, шрифты и дополнительные ресурсы размещайте в `assets/`. Прочие файлы из корня автоматически не публикуются. Локальные `.env`, служебные файлы, скриншоты и README не входят в публикацию.

Перед публикацией проверяются синтаксис JavaScript и наличие локальных ресурсов HTML/CSS. При технической ошибке остаётся предыдущая рабочая версия. Проверки не оценивают правильность текста и дизайна.
